RAW MILK WEBSITE

Files:
- index.html and style.css: your existing home page, kept in place
- benefits.html and benefits.css: expanded Benefits page
- aboutus.html and aboutus.css: About Us page with 11 team-member cards
- script.js: small demo handler for the home contact form
- hero.png, about.png, ecofriendly.png, unadulterated milk.png: supplied images

HOW TO USE:
1. Keep all files and images in the same folder.
2. Open index.html in your browser.
3. Use the navigation to open Benefits and About Us.
4. On aboutus.html, replace each "Add Photo 01" placeholder with an image element, for example:
   <img class="member-photo" src="member1.jpg" alt="Member Name 1">
   Then add the member-photo CSS:
   .member-photo { width:100%; aspect-ratio:4/4.3; object-fit:cover; border-radius:9px; }
   Keep the image file in this same folder and update the src filename.
5. Change "Member Name 1" and the suggested titles to your actual names and roles.
